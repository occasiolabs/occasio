Occasio

Occasio is the local black-box recorder for AI coding agents.

Tamper-evident, Sigstore-signed audit trail for Claude Code and other AI coding agents. Local-first audit and policy proxy. Built by Occasio Labs.

Install

npm install -g @occasiolabs/occasio

What it does

  • Black-box recorder — every tool call your AI coding agent makes is captured locally.
  • Tamper-evident audit logs — hash-chained, Sigstore-signed pipeline events.
  • Local-first audit and policy proxy — runs on your machine, no cloud, no telemetry.
  • Policy enforcement — deny-list, path enforcement, secret redaction, transform rules.
  • Claude Code security and MCP security — native interception of Read, Glob, Grep, TodoWrite, plus MCP routing.
